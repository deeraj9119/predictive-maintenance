# Project 1: Predictive Maintenance Classification

This repository contains a predictive maintenance classification project using machine learning.

## Contents
- Dataset exploration and preprocessing
- Model training with Logistic Regression and Decision Tree
- Hyperparameter tuning and evaluation
- Model serialization for deployment

## Workflow
1. Load and inspect the dataset
2. Perform exploratory data analysis and visualize outliers
3. Encode categorical features and scale numerical features
4. Split data into train/test sets
5. Train and evaluate Logistic Regression and Decision Tree models
6. Compare metrics and save the best model
